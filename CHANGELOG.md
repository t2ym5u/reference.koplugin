# Changelog

All notable changes to this project will be documented in this file.

## [1.0.2] - 2026-11-04

### Fixed
- The tool no longer crashes when an outdated plugin is installed alongside:
  shared modules left behind by an older plugin are replaced by this
  plugin's own copy instead of being used as they are.

## [1.0.1] - 2026-11-04

### Changed
- Uses less memory: the tool loads when you open it, not when KOReader
  starts, so it no longer takes memory or startup time while unused.

## [1.0.0] - 2026-11-03

### Added
- Periodic table of the 118 elements (French and English names, atomic
  masses, groups, periods, families shown as grey patterns with a legend);
  tap an element for its details. Whole table in landscape; whole table or
  a zoomed half (groups 1–9 / 10–18) in portrait.
- NATO/ICAO spelling alphabet with "Spell a word", and the Greek alphabet.
- Morse table, on-screen Morse keyer with live decoding, and text → Morse.
- Multiplication tables 1–12 and 12 × 12 grid, squares, cubes and powers of
  2 up to 20, SI prefixes (including ronna, quetta, ronto, quecto).
- On-screen ruler in centimetres and inches from the screen DPI, with a
  remembered calibration.
- French, Spanish and German translations.
